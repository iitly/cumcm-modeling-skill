# 本技能的维护记录与取舍原则

最后整理：2026-11-16（北京）。本文件说明 skill 如何演进、哪些旧规则被撤销及原因，供未来维护者判断“这条要不要信”。

## 1. 本记录的用途

这里只保留历史撤销项与维护取舍，不另立一套权限或质量门。当前授权、封版保护和验收均按主文件；明确要求本轮改良就是本轮授权，不重复索取同意。

回退副本和审计记录保存在用户约定的数据盘维护目录；具体运行记录不灌进每次加载的主流程。

## 3. 语言观察的证据边界

旧维护笔记引用过小样本语料频率。本轮未重建其取样、提取与统计检验，不能据此断言某种标点是稳定 AI 特征，也不能把“未发现差异”升级为统计等效。具体旧数值留在版本备份，不再充当执行依据。

语言清理只修可定位的冗余、病句和套话，按 `references/writing-delivery.md` 保留用户措辞与断言强度；不用字词频率判断作者身份或保证检测结果。

## 4. 吸收外部 skill 的边界

2026-11 参考 `liwen778/cumcm-agents`（commit `17842c5`）：

**采纳**：题意逐项对账、数据体检与清洗留账、逐问证据包、复核者自查证据、数字单一来源与联动更新、模板母本与工作稿分离。

**不采纳**：固定 LaTeX 路线、每问至少三张图、手动逐张保存图片、固定缺失值填法、强制双智能体反复审到通过、把“裁判角色”当正确性保证。

详见 `references/cumcm-agents-adoption.md`。

## 5. 经验数据的边界

`references/竞赛实证锚点.md` 记录了 59 份获奖论文的摘要/图/表分位数。它们是**观察值**，来源与提取口径已标注，不是官方阈值，也不预测获奖。引用时必须说明这一点。

`references/华数杯经验总结.md` 保留历史案例与检索线索，其中的算法分级、题号映射等旧归纳已撤销。

## 6. v3.1 修正方向（记录，不另立执行规则）

主文件与参考冲突时修正文原句，不仅加“以新条为准”。本轮清理了延迟/全摆幅时间混用、同公式自证、缩放固定量冲突、原始表格缓存处理、主源覆盖与未授权装包、格式条款跨事项泛化、旧语料统计的过强结论。

校验器现在检查每份 Markdown 的根路径引用、围栏、根目录边界与 Python 语法；旧规则引文只在显式例子区间豁免，不能整文件白名单。回归用故意造坏的独立副本，保留先前漏检证据；通过项数只是机械检查次数，不代表全部数学/科学主张正确。行为测试记录实际模型、真实操作、文件指纹和覆盖场景，未测项不算通过。
