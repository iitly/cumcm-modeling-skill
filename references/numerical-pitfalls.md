# 数值与单位陷阱

最后更新：2026-11-16（北京）。这里只列会影响实现的风险；不是所有题共同的算法门槛。验证选择见 `references/model-validation.md`，CMOS 题另读 `references/cmos-ring-oscillator-physics.md`。

## 1. 先定义量，再统一单位

把单位、参考方向、定义域和尺度写清。量纲正确是必要检查，不保证对象/方程正确；SI 与配套紧凑单位均可用，不能因出现换算因子就判错。

题面单位可疑时保留原文并回原图核对，必要时比较有依据的分支，不能直接改源。常用换算为 1 fF/μm² = $10^{-3}$ F/m²、1 μm = $10^{-6}$ m、1 fF·V/μA = 1 ns（电容/电流本身是 s/V）。

## 2. 优化：没有方向信息，不等于证明无解

- **常数/异常目标**：全零可能是真实结果，也可能是约束掩码、单位、变量未更新或稀疏可行域。逐项检查约束残差、有限值和小例，不能把零直接等同不可行，更不能把 NaN 当零参与优化。
- **有限预算内定位**：按问题结构选择可行性子问题、松弛、可行初始化/修复、采样或低维粗网格；高维全网格不作通用救法。限制到局部区域后要报告范围变化，不把局部结果叫原全域最优。
- **停止状态**：例如 SciPy DE 的终止涉及种群目标值离散程度；常数种群可能满足停止条件，但不同算法/约束实现不保证都立即停止。核实际版本、状态、调用预算和失败原因，不从“一步停止”反推唯一原因。
- **数学保证**：局部方法在相应光滑性、约束资格、步长等条件下才有到驻点/KKT 的收敛结论；凸性等额外结构才可能支持全局最优。启发式解应核可行性；有有效界才报 gap，没有界就写未证最优，不编 gap。
- **整数性**：连续松弛解舍入后回代原约束，不能只核目标值。

SciPy DE 参数与终止定义的正式来源：`https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.differential_evolution.html`；使用时核本机版本，不靠此引用推定所有优化器行为相同。

## 3. 方程与离散

- 按误差、刚性、事件与资源选择求解器。RK45/ode45 是非刚性候选；电路或化学题不必然刚性，发现快慢尺度/步长受限时再核 Radau/BDF/ode15s 等适用方法。
- Crank–Nicolson 对适用的线性扩散离散有稳定性结论，不保证任意 PDE 下无振荡或准确；把空间、时间离散及边界一起核。
- 只有一对网格/步长结果，通常只能报告该次变化，不能无参考解就宣称收敛阶。估阶需有参考解误差或足够分辨率层级，并核渐近区、舍入/迭代误差的影响；小变化也可能是共同偏差。
- 先写真实守恒量及必要密度/几何权重；离散恒等式的小残差不自动证明物理模型正确。积分区间、事件时刻和变量定义有误时，数值表再精确也不补救。

## 4. 随机与统计

区间、样本单位、依赖和有效样本量按 `references/model-validation.md` 执行。MCMC 检查多链/迹图/自相关/ESS 等适配诊断，单链不适用某诊断时如实说明；不把每个任务硬套同一套指标。零事件不能证明真概率为零。

## 5. 合理性诊断不预设正确答案

| 观察 | 要排查的方向（不是已定原因） |
|---|---|
| 结果全零或多组相同 | 原始输入与身份键、分组映射、单位、掩码、更新逻辑；也允许经核实的真实相同 |
| 数量级异常 | 对照明示单位、定义和尺度，而不是迎合“理应有差异” |
| 求解过早停止 | 实际停止条件、可行性、非有限值、容差和评价预算 |
| 拟合高但外推差 | 可用信息时点、泄漏、选择偏差、范围变化 |
| 不确定区间相同 | 核原始重复结果及计算；理论上相同也可能合理 |
| 图文数字不同 | 运行身份、单位、舍入、结果版本及导出链 |

仅对题中真实定义适用的边界做检查，例如概率范围或计数整数性；不能把热泵 COP 等性能系数误当必须 ≤1 的能量转换效率。异常先查证再解释，不为预想趋势改输出。
