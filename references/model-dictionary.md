# 模型候选索引：先看问题结构，再选方法

最后更新：2026-11-09（北京）。这是选型目录，不是算法优劣、创新性或奖级排名；遇到具体模型先核适用条件与正式文档/教材，再设计本题的最小验证。未核过的特殊数学保证不能从本索引推定。

## 使用顺序

1. 从题意台账确定要估计、预测、解释、决策还是模拟；同一道题可混合类型，不凭 A/B/C 题号分流。
2. 核数据含义、规模、时间/实体边界、变量类型、约束、可用算力和截止。
3. 先找简单且可验证的基线，按真正会改变选择的证据比较候选；没有必要不遍历整张目录。
4. 方法输出若不是题目所需，就继续建模，不用“模型名字高级”掩盖任务错位。

## 1. 优化与调度

| 问题结构 | 可考虑的方法 | 选型前要核的事项 |
|---|---|---|
| 线性目标/约束 | LP；单纯形、内点等现成求解器 | 线性化是否改变原问题、变量界、尺度和可行性；算法不按维数一刀切排名 |
| 整数、0-1 及逻辑决策 | MILP、约束规划；分支定界/割平面等 | 整数性和逻辑约束是否完整；报告可行解、最优界、gap、停止原因 |
| 光滑连续非线性 | 梯度/牛顿、SQP、内点、信赖域等 | 可微性、导数、凸性/非凸、多起点和约束处理；局部收敛不等于全局最优 |
| 多目标取舍 | 加权、ε-约束、目标规划、Pareto 搜索/NSGA-II | 目标尺度、偏好来源和可行性；权重不是无依据调到想要的方案 |
| 多阶段状态决策 | 动态规划、值/策略迭代、DDP、近似动态规划 | 状态与决策、转移、终端条件、状态规模以及近似误差 |
| 复杂黑箱或难精确求解 | DE、GA、PSO、模拟退火、蚁群及其他启发式 | 编码、可行性、评价预算、多次运行和精确小例/界；不能预定某算法永远更准 |
| 大规模可分结构 | 列生成、Benders、拉格朗日松弛等 | 主/子问题结构、适用假设、上下界和停止条件；不是添加算法名就构成创新 |

## 2. 预测与回归

| 任务/数据 | 可考虑的方法 | 检查重点 |
|---|---|---|
| 有序时间序列 | 持续性/季节基线、移动平均、指数平滑、ARIMA/SARIMA | 合法预测时点、趋势/季节结构、滚动验证、残差及预测区间 |
| 带协变量的回归 | 线性/多项式回归、岭/LASSO/弹性网、SVR、GPR | 关系形式、共线性、正则化、样本量与模型容量、合法特征及留出误差 |
| 非线性表格数据 | 随机森林、梯度提升/XGBoost 等 | 基线是否足够、调参预算、时间/分组划分、误差分层与解释边界 |
| 可合理表达的季节/事件影响 | 回归、结构化时序、Prophet 等 | 外生变量在预测时是否已知，参数和事件选择不能用最终测试集 |
| 序列网络有明确必要性 | LSTM 等神经模型或物理/统计混合模型 | 数据和资源是否足够，是否真正优于简单基线，物理约束与外推风险 |
| 小样本趋势 | 简单趋势/机制模型；有适用依据时考虑灰色模型 | 小样本不自动满足指数趋势；有限数据上的拟合好不证明预测可靠 |
| 已知演化机理 | Logistic、SIR/SEIR 或本题 ODE 等 | 参数可标定性、观测机制、初始/边界条件、识别和验证数据是否独立 |

不按“50 个点用回归、100 个点用 ARIMA”这类固定切线选型，也不把复杂模型默认称为创新。

## 3. 分类、判别与聚类

- 分类/判别候选：逻辑回归、LDA/Fisher、距离判别、KNN、SVM、随机森林、梯度提升、Bayes 判别等。先明确标签、误判代价、类别不平衡、阈值和验证方案；不能拿线性回归直接冒充分类概率模型。
- 聚类候选：K-Means、层次聚类、DBSCAN、谱聚类、GMM、FCM 等。先核特征语义、尺度/距离、簇形与密度、样本量、稳定性和解释方式，不从“高级”名称推定更合适。
- 分类有标签、聚类通常无监督；不能把两者或“相关性分析/预测解释”当同一任务随意替换。

## 4. 综合评价与决策

候选包括加权和、AHP、熵权/CRITIC/变异系数等赋权、TOPSIS、VIKOR、ELECTRE/PROMETHEE、模糊综合评价、ANP/DEMATEL 等。先区分指标构造、赋权、聚合与决策，各环节有不同作用，不能为凑模型任意叠加。

检查指标方向和量纲、重复信息、权重依据、排序反转/敏感性以及硬约束。数据驱动权重不自动代表“价值客观正确”；AHP 的专家判断必须有真实来源，不能 AI 造判断矩阵后声称已咨询专家。

## 5. 物理机理与反问题

- ODE：欧拉/改进欧拉、RK4、自适应显式或隐式求解器等，按刚性、误差、守恒与资源选择，不能把 ode45/RK45 写成任何 ODE 都适用。
- PDE：有限差分、有限元、有限体积等；具体格式（如 Crank–Nicolson）的稳定性结论需注明方程、离散与假设，不把特定线性扩散问题的性质推广到所有 PDE。
- 参数辨识：线性/非线性最小二乘、LM/其他适用求解器、全局搜索及有依据的统计方法。先查可辨识性、单位、边界、观测误差和不同参数组合是否等效。
- 近似/渐近模型：核所保留/舍去的项，代回原方程和边界；机理合理、参数可标定、计算可行是工程题的优先依据，不强迫所有数据题变成机理题。

## 6. 图论、网络与路径

| 结构 | 候选 | 风险点 |
|---|---|---|
| 最短路 | Dijkstra、Floyd–Warshall、A*、双向搜索等 | 负权、单源/全源、启发式条件和图规模；不把不同任务的复杂度直接排名 |
| TSP/车辆路径 | 小规模精确模型、最近邻/局部搜索、LKH、模拟退火/蚁群等 | 真实路程/时间、容量与回路约束；LKH 等启发式输出不自动带全局最优证明 |
| 流与匹配 | 最大流、最小费用流、Dinic、网络单纯形、指派方法 | 容量、守恒、成本、需求/供给及多商品耦合 |
| 连通与结构 | 并查集、Kruskal/Prim、中心性、社区发现、着色/团等 | 节点/边/权重定义、方向与周期边界；结构指标不自动给因果解释 |

## 7. 统计与数据分析

候选包括 Pearson/Spearman/Kendall、互信息、偏相关、回归；PCA/因子分析、核方法、t-SNE/UMAP；t/χ²/ANOVA/MANOVA 或适用的非参数检验。

先确定分析单位、相关结构、分布/采样与检验假设。描述性相关系数和显著性推断的条件分开；降维可视化与可用于后续预测的变换分开；控制多重比较和选择偏差，相关不自动成为因果。

插值/拟合候选：线性、样条、B 样条、NURBS、克里金等，按数据与约束选择；“更平滑”不等于更准确，不用未来值帮助过去时点预测。

## 8. 随机模拟与随机过程

候选包括直接/分层/重要性抽样、蒙特卡洛、MCMC/Gibbs、马尔可夫链/HMM/MDP，以及适用的排队模型和网络。

核随机分布和依赖、稳态/收敛、有效样本量、稀有事件和估计量方差。MCMC 样本不能无理由当独立 Bernoulli；排队模型需核到达/服务假设、稳定负载和适用时段。

## 9. 博弈与交互

零和、纯/混合策略、产量/价格竞争、演化/合作博弈及 Shapley 值等，只在确有参与方、策略、收益与互动假设时使用；解释均衡概念、存在性/求解条件与现实边界，不能把求得一个固定点直接称唯一均衡。

## 10. 模糊与不确定评价

模糊综合评价、FCM、模糊规划、直觉/犹豫或二型模糊等是候选，不是层级。隶属函数、专家数据和容忍度要有依据；模糊隶属度、随机概率、置信度不能混用。

## 11. 动力系统与稳定性

相平面、线性化特征值、Lyapunov、分岔/中心流形，以及差分方程、Z 变换、具适用依据的记忆模型等。局部/全局、连续/离散、线性化/原系统、理论/数值证据分别写清。

## 12. 离散组合与工程布局

排班、装箱、覆盖、匹配、切割与布局可考虑整数/约束规划、动态规划、贪心或专用启发式。先查变量和组合结构，再比较可行性、规模、界与预算；不要因为 NP-hard 就放弃精确小例或基线。

验证方式统一见 `references/model-validation.md`。本目录不替代具体问题的数学推导、方法出处与真实实现。
