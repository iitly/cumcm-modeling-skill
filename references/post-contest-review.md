# 赛后：评估、公告核对与答辩

最后整理：2026-11-09（北京）。实际提交件始终只读；本文件描述赛后可以做什么、不能声称什么。

## 1. 奖项复盘

- 先读**实际提交版本**的全文与附件，不用旧对话、草稿或未提交源码代替。
- 按官方四标准（假设合理性、建模创造性、结果正确性、表述清晰度）分别列可核实的优点，以及能定位到页码/章节的实质缺陷，说明是否影响主结果。
- 区分三道关：赛区获奖、报送全国评阅、全国获奖。异地名额不能换算本赛区概率；名称相近的其他省赛不得混入。
- 缺同题评阅细则、竞争论文和本赛区推国名单时，只给条件判断；不承诺奖级，不报未经校准的百分比。
- 说明判断来源：是沿用既有上下文，还是本轮重新评审。

## 2. 公示名单核对

公示常以公众号图片发布，流程：

1. 先读通知首页：赛事、赛区、公告性质、落款、“具体见附件”。单张通知首页没有队号 **不能** 判未入选。
2. 把用户提供的全部图片按页码排齐，确认是否覆盖完整附件；区分本科/高职分组，注意附件切换位置，别把下一组续表算进上一组。
3. 图片直链可用 `vision_analyze(image_url=...)` 读表。密集表格先读全页，用浏览器的 `document.images[0].naturalWidth/naturalHeight` 确认原图尺寸，再对目标号段用 `region=[x1,y1,x2,y2]` 放大复核。辨不清就写“未能辨清”，不靠猜补号。
4. 用**报名号完整字符串**精确匹配，再交叉核对姓名与学校。论文文件名前缀、题号与公告“报名号”可能是不同字段，先确认映射。名单按编号排序时，读目标前后行，并分别扫描不同推荐等级区块和跨页续表；“同校有队伍”不等于本队在内。
5. 报结果时先给结论与证据页码，再说边界：仅附件完整时才能说“本次推国公示未列该队”；“推荐等级国一/国二”不是已获国奖；未列推国不等于违规认定或省奖结果；公示期内可能有更正。

此前奖级预测如过于乐观，直接承认并收回；用户失落时少说套话，保留资料供后续复盘。

## 3. 答辩与核验咨询

- 先查当届全国评阅规范与所属赛区正式通知，再区分：赛区定奖前的面试、全国评阅、获奖后的异议调查。不要把“国二”当自动触发全国答辩或违纪审查的条件。
- 全国评阅规范要求赛区组织面试，但范围和方式由赛区自定。公众号经验、他省差额面试的“推国即答辩”、固定时长、PPT 或现场跑代码，都不能推断为本赛区每支队的义务。
- 同一篇经验文对流程说法前后冲突时，标出矛盾，不据此安排必做流程。
- 查不到本赛区当届通知时明确说未知，不造“大概率”。用户担心被抽查时，先给结论和当前程序阶段，再解释普通核验不等于被认定有问题。
- 收到实际通知后按其要求准备：模型解释、代码复现、如实披露的 AI 使用；不改封版提交件。

## 4. 答辩练习包（以封版论文为准）

**分工**：按用户要求可分配技术主答、材料定位、数字复述等练习任务，但必须写明“练习分工 ≠ 赛期真实贡献”。论文匿名时无法从论文推断队员人数和分工，不得编造三份职责。队伍人数以用户最新确认的报名信息为准。

**第一步：页码证据表**

1. 只读确认实际提交的 PDF、页数、指纹；用 PyMuPDF 逐页提取摘要、各问要求/方程/参数/结果、验证、局限、AI 声明。
2. 先核对 PDF 页序与印刷页码是否一致，再把每个待讲数字绑定到具体页；公式文本层有上下标歧义时按 `pdf-formula-verification` 核对。
3. 不用旧对话或未提交源码代替封版证据。

**第二步：一页答法卡**

每问一行：“要什么 → 怎么做 → 关键数字”。验证只讲论文确实做过的项目，注明“离散自洽 ≠ 真实物理正确”；实质瑕疵各用 2–3 句口语承认、限定影响、指明主结果证据。数字和关键判断后就近写页码。

要求严格一页时，在草稿区生成 A4 文件，用 `fitz.open(成品).page_count` 确认等于 1，抽取尾段文本确认未丢，再渲染检查裁切与乱码。不把聊天里看着短当物理一页，也不把练习文件写回封版目录。

**第三步：分层追问库**

按用户指定题数从浅到深排，单题一行“问题 → 口语答题要点 → 页码”，覆盖模型选择、参数来源、结果判据、验证局限、AI 使用。备查库才放 1/3 分钟稿、逐问串讲、参数公式速查与深水区解释；用户只要前两项时不要抢先输出第三项。

**第四步：模拟**

按用户指定轮次和每轮题量连续追问，中途不提示、不替答。全部答完再按“准确性 → 漏掉的页码证据 → 口语表达 → 下一轮补课点”讲评。卡壳处用直白类比讲清，不粉饰论文已识别的缺口。

## 5. 资料与临时文件

用户指定项目子目录时，先查是否存在，只在该目录放正式交付文件；临时产物用专用 scratch，交付后清掉。原提交件始终只读。
