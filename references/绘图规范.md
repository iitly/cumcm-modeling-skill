# 图表规范：数据准确、含义清楚、输出可复现

最后更新：2026-11-09（北京）。图表服务于论证，不按数量、配色或“手画感”判 AI/奖级。程序图和自绘机理图都是表达工具，不能替代真实理解和来源证明。

## 1. 画图前

先写要回答的问题、输入数据和图支持的具体判断；如果只是探索，不预写尚未得到的结论。选择可清楚表达该数据形态的图，图不增加证据时用表或文字即可。

需要解释几何、边界、拓扑、判定情形或反馈时画可追溯示意图，标关键对象/单位/方向，非按比例注明。只画本题真正存在的机制，不按奖级凑张数。

## 2. 选图参考

| 内容 | 常用候选 | 注意事项 |
|---|---|---|
| 分布 | 直方/箱线/散点/小提琴 | 样本少时直接展示点；带宽、分箱和汇总会影响观感 |
| 分类比较 | 点图/条形/柱形 | 位置与尺度有意义；仅均值可能掩盖分布，柱形通常用零基线 |
| 有序时间/迭代 | 折线、分面 | 不连接没有顺序含义的类别；区间只在有真实依据时添加 |
| 连续关系 | 散点、拟合/参考线 | 相关不自动是因果；非线性和异常点如实保留 |
| 占比 | 条形/堆叠；少数明确类别可用饼/环图 | 比较精确大小时位置/长度更易读；不把非占比当整圆 |
| 参数/相关矩阵 | 热力图、分面、龙卷风等 | 按数据选择顺序/发散色图，色标范围与单位清楚 |
| 路径/调度/网络 | 地图、甘特图、网络图 | 位置/时间/节点和边有真实语义；地图底图合规另核 |
| 几何/函数三维关系 | 3D 示意/曲面或二维投影 | 只有第三维确实有信息时用三维，避免透视遮挡和装饰性立体 |

双 Y 轴、截断坐标、对数尺度等并非天然造假，但容易误读。先比较分面/归一基准等替代；确需使用时明确单位、转换和截断，不夸大差异。默认配色可用，只要足够可辨且不造成歧义；不为“高级感”强行换图。

## 3. 每张图按需配元素

- 数据图标对象、轴含义与适用单位；无量纲写清定义。图题/图注与正文指代一致，多系列用直接标签或图例区分。
- 颜色、线型/标记冗余编码；必要时检验色盲和灰度可辨性。网格、阈值线、关键点标注只在帮助读值或理解时加，不每图强制添加。
- 多面板图可用于真实关联的对照，共享尺度/单位并明确标签；无关联的独立结果不静默拼图掩盖，等大布局或不等大布局按信息选，不硬分“主角面板”。
- 误差棒/阴影须有实际数据与计算，写明 SD/SEM/置信或其他不确定区间、样本单位和 n；确定性结果不凭空加区间。
- 不为美观删点、改值、伪平滑或缩坐标。异常/不可达值不能藏起来，处理须与数据账一致。

## 4. 尺寸、字体与导出

按最终排版尺寸设计并在目标尺寸下看清文字；插入文档后可以合理缩放，但必须重查最终字号、线宽和可读性，不用某个英寸/点数作为所有论文通用门槛。

线图/示意图优先矢量，照片/密集栅格用合适位图；PNG 可作预览，位图分辨率按目标尺寸与当届要求定。自动保存并记录源数据与脚本，源文件不要靠用户手动点保存来维持复现。

中文字体先查本机可用字形，见 `references/matplotlib-chinese-font.md`；不把写了字体名当作没有缺字。文档与图的字体协调即可，不强迫所有场景同一字体。

## 5. 视觉验收

依次检查数据语义/单位/图型、数值与来源、坐标范围/标记、图例遮挡、缺字、裁切/重叠和最终尺寸可读性；实际读取渲染预览。复杂数据图可按需用 `scipilot-figure-skill` 辅助，但先核本机脚本与接口。

正式正文中先让读者知道图表在回答什么，再给有信息的解释；不固定每图后至少三行，也不逐字复读轴标签。若只有表更清楚，就不强画图。
