## 1. 三个积木

```python
# ① 圆角矩形节点
def box(ax, x, y, w, h, text, fc=BLUE, tc='white', fs=9, sub=None):
    p = FancyBboxPatch((x-w/2, y-h/2), w, h,
                       boxstyle='round,pad=0.008,rounding_size=0.03',
                       fc=fc, ec='none', zorder=3)
    ax.add_patch(p)
    ax.text(x, y + (0.10 if sub else 0), text, ha='center', va='center',
            fontsize=fs, color=tc, zorder=4, fontweight='bold')
    if sub:
        ax.text(x, y - 0.14, sub, ha='center', va='center', fontsize=7,
                color=tc, zorder=4, linespacing=1.25)

# ② 菱形判断框
def diamond(ax, x, y, w, h, text, fs=8):
    ax.add_patch(Polygon([(x-w/2, y), (x, y+h/2), (x+w/2, y), (x, y-h/2)],
                         closed=True, fc=ORANGE, ec='none', zorder=3))
    ax.text(x, y, text, ha='center', va='center', fontsize=fs, color='white',
            zorder=4, fontweight='bold')

# ③ 箭头连线
def arrow(ax, x1, y1, x2, y2, color=GRAY, rad=0.0, label=None, ly=0):
    ax.add_patch(FancyArrowPatch((x1, y1), (x2, y2),
                 connectionstyle=f'arc3,rad={rad}', arrowstyle='-|>',
                 mutation_scale=12, lw=1.3, color=color, zorder=2))
    if label:
        ax.text((x1+x2)/2, (y1+y2)/2 + ly, label, ha='center', fontsize=7.5,
                color=color, zorder=4, bbox=dict(fc='white', ec='none', pad=0.8))
```

## 2. 布局经验（不是普适数值）

旧稿的“框高 ≥1.1、间距 ≥0.24 数据单位”只在**坐标范围 0–5.4、轴高约 4 in、字号 9pt 两行**这一组参数下成立。换画布或坐标范围后按下面关系重算，或直接用 axes 分数坐标/显示坐标定位文字：

$$h_{data} \approx \frac{(f_{pt}/72) \times \text{行数} \times \text{行距}}{\text{轴高(in)}} \times y_{range}$$

（例：9pt × 2 行 × 1.25 行距、轴高 4 in、$y_{range}=5.4$ → 文字块约 0.42 数据单位，再加上下留白才是框高。）

同理，`pad=0.008`、`rounding_size=0.03` 也是数据坐标单位，换 `xlim/ylim` 后视觉大小会变，按比例缩放或改用 `mutation_scale`。

其他可复用做法：

1. 两行文字用 `\n` + `linespacing=1.25`，不要用 `|` 拼单行。
2. 按真实算法给每条分支标明条件，左右方向由布局决定，不强制右“否”左“是”。
3. 回环避开节点与文字，箭头方向和停止条件可辨。
4. 步骤框交替配色，开始/结束用灰色圆角；一张图内配色克制，不超过三族。
5. 注记放图两侧空白，不压主流程。
6. 流程图字号可比数据图略大（评审打印后要能读），最终按实际尺寸目检。
7. 出图后看灰度版，确保颜色不是唯一区分手段。

## 3. 自检清单

- [ ] 节点内主/副标题无重叠、无溢出
- [ ] 是/否分支标注清晰，回环方向正确
- [ ] 中文与符号无方框：**目检或像素检查**，不能只依赖“无 Glyph missing 警告”（部分版本静默画方框）
- [ ] 灰度版可辨
- [ ] 图注与正文引用一致，图能对应明确结论

## 4. 常见图型

| 图型 | 常放位置 | 作用 |
|---|---|---|
| 技术路线图 | 问题分析末尾 | 展示整体思路与各问关系 |
| 核心算法流程图 | 模型求解节 | 展示分支、回环与停止条件 |
| 模型框架图 | 模型建立节 | 展示层级或模块关系 |
| 数据流/预处理流程图 | 数据处理节 | 展示清洗与特征构造过程 |

是否“必须有”取决于本题是否需要解释这些关系，以及当届评阅细则；不按奖级规定图型数量。
