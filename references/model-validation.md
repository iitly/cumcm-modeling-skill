# 模型验证：按风险选择证据

最后更新：2026-11-16（北京）。验证的对象、数据、口径和结论范围先写清。以下是选择清单，不是每题全做的配额；结果复现、数值互验、留出预测、外部实验的证据强度不同。

## 1. 先确定要排除什么错误

| 风险 | 可用检查 | 不能据此声称 |
|---|---|---|
| 读错题意/图/附件 | 原始出处逐项对账、图像拓扑/参考方向复核、歧义口径比较 | 仅通过方程代回就已正确理解题意 |
| 方程或单位错误 | 量纲、极限、特例、守恒量及边界条件核验 | 量纲正确就物理正确 |
| 代码没有实现公式 | 单元小例、已知答案、逐项对应、独立实现 | 同一函数被调用两次就是独立验证 |
| 数值离散误差 | 网格/时间步/容差收敛、算法对照 | 稳定运行或小残差就接近真实物理量 |
| 统计/预测过拟合 | 合法留出、时序/分组验证、简单及有竞争力的基线、误差分层 | 样本内高拟合度等于新工况泛化 |
| 约束/求解失真 | 原尺度可行性、整数/逻辑检查、上下界、小规模精确解、gap/停止状态 | 启发式收敛或找到可行解就全局最优 |
| 权重/评价脆弱 | 现实范围内扰动、排序稳定性、替代口径、删改指标影响 | 客观赋权方法自动保证价值判断客观 |
| 随机或抽样误差 | 实际重复、置信/不确定区间、有效样本量和诊断 | 固定一种子等于结果普遍稳定 |
| 假设和参数脆弱 | 有依据的扰动、联合情景/交互、替代假设、失败边界 | 任意取 ±10% 后结论不变就普遍稳健 |

## 2. 参数与误差

- 扰动范围从测量误差、附件波动、合理业务/物理边界或明确的情景假设中定；无依据则标探索范围，不虚称实证。
- 单参数分析可用于局部筛查，但要说明它没覆盖交互；参数强耦合时使用适合任务的联合扰动、LHS、Sobol 等候选，先核其假设与成本。
- 区分观测/抽样、模型结构、参数估计、近似与离散误差。不把其中一项小当总误差小；缺乏信息就标未量化，不能编一个误差上限。
- 报告“在哪个范围、哪个指标、误差有多大、何时失效”，不只写模型稳健；改进要有同口径对照，也报告代价和失败情形。
- 比较前锁任务、样本身份键、单位/归一化、划分、基线、主指标和算法预算；精度、速度、资源分别报。测试集不能参与选模型/调参，重复试验后挑最好一次也须如实交代；已经用于选择的数据不再是未见测试集。保留普通基线和失败方案的真实结果，不用弱化对照或改指标制造改进。

## 3. 概率、随机模拟与区间

1. 按题意说明随机变量、分布、依赖与分析单位。题目说“任意”不自动等于某一均匀分布；分布不明就列假设和敏感性。
2. 报实际模拟次数、事件计数/样本量、种子策略及不确定性。次数由目标精度、稀有事件程度和预算确定，不设所有题通用的合格下限。
3. 独立同分布的二项比例可考虑 Wilson 等适配区间，写清前提与置信水平。相关样本、加权比例、连续量、MCMC 或自适应抽样须换适配方法，不能照套。
4. 多种子/样本量/收敛曲线按实际风险选。确定性计算不强行造随机重复或“±”；零事件不等于真概率为零。
5. SD、SEM 和置信区间含义分开，图注标清样本单位、n 和计算方式；有效样本量不自动等于观测行数。

## 4. 解释与跨问一致性

- 概率、成本、时间、量纲与非负/整数要求按本题定义核，异常结果可以是真实发现，先验证再解释，不为符合直觉修改输出。
- 只对真实共享的变量、输入输出和假设做跨问检查。同一量口径改变时先给映射；不同工况/目标的区间无需强制互相包含。
- 没做干预/识别或机制证据时，把数据关系称为相关、拟合或预测关联；模型解释工具不能单独证明因果。
- 机理解释能指回方程/数据/对照，不能先给想要的原因再编数支持；无法确认就把候选解释与结论分开。

## 5. 通过和未完成

验证表逐项登记：风险、方法、实际运行/原始证据位置、结果、适用范围、未决项。不存在的检查不能填 ✓，不适用要写理由。

主答案错误、关键数字无来源、明显泄漏或合规阻断不能放行。未做的扩展或高成本外部验证可以作为局限交付，但不得把局限隐藏后声称全部验证完成。修订后只复验受影响的依赖链，证据更新规范见 `references/data-evidence-review.md`。
